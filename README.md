### Create Smarter. Publish Better.

PostPilot is an AI-powered social media content strategy and
publishing assistant designed to simplify content planning,
optimization, scheduling, and account management.

## Core Features

- AI-assisted title and description optimization
- Hashtag and keyword recommendations
- Personalized content topic suggestions
- Content calendar and scheduling
- Multiple social account management
- Publishing status and notifications

## Technology Stack

- Frontend: React and TypeScript
- Backend: Java and Spring Boot
- Database: PostgreSQL
- Version Control: Git and GitHub

## Project Status

Under development.

## Vision

Reduce repetitive work for content creators through
intelligent recommendations and automation.
